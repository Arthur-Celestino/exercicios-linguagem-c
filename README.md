# Exercícios de Programação em C

### Professora Karina Alves de Melo - 06/10/2026

Este repositório contém exercícios desenvolvidos durante as aulas de programação em linguagem C. 
Os exercícios trabalham conceitos básicos como entrada e saída de dados, condições, `switch`, 
laços de repetição, cálculos e médias.

## 📚 Exercícios

### Exercício 1 - Verificação de idade
O programa recebe a idade de uma pessoa e informa se ela:
- Ainda não pode votar;
- Possui voto facultativo;
- Possui voto obrigatório.

### Exercício 2 - Conversão de Dólar
O programa recebe a cotação do dólar e um valor em reais.
Depois, calcula e mostra quanto esse valor representa em dólares.

### Exercício 3 - Média Ponderada
O programa recebe três notas e calcula a média ponderada.
As notas possuem pesos diferentes:
- Primeira nota: peso 2;
- Segunda nota: peso 3;
- Terceira nota: peso 5.

### Exercício 4 - Dia da Semana
O programa recebe um número de 1 a 7 e utiliza `switch` para mostrar o dia da semana correspondente.

### Exercício 5 - Dias do Mês
O programa recebe o número de um mês e informa se ele possui:
- 28 dias;
- 30 dias;
- 31 dias.

### Exercício 6 - Números Pares
O programa utiliza um laço `while` para percorrer os números de 1 a 50 e mostrar somente os números pares.

### Exercício 7 - Soma de Números
O programa permite que o usuário digite vários números.
Os valores são somados até que o usuário digite `0`, que encerra a entrada.
No final, é mostrada a soma total.

### Exercício 8 - Média das Idades
O programa solicita a idade de 5 pessoas, soma os valores e calcula a média das idades.

### Exercício 9 - Série Harmônica
O programa recebe um número `N` e calcula o valor da série harmônica:

**1 + 1/2 + 1/3 + ... + 1/N**

O resultado é mostrado com duas casas decimais.

## 🛠️ Tecnologias utilizadas

- Linguagem C

## 🎯 Objetivo

Praticar os principais conceitos iniciais da programação em C, como:

- Variáveis;
- `scanf` e `printf`;
- `if`, `else if` e `else`;
- `switch` e `case`;
- `while`;
- `for`;
- Operações matemáticas;
- Médias e cálculos;
- Entrada e saída de dados.
